# Pokédex — Polished Python Clone

A polished, responsive Pokédex web app inspired by modern Pokédex interfaces, implemented as a Python Flask application with an original UI.

## Run
```bash
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
# Windows
# .venv\Scripts\activate

pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

The frontend fetches live Pokémon data from PokéAPI. PokéAPI provides Pokémon resources and evolution-chain endpoints.
